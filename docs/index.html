Pads run 1–4 across the top, then 5–8 across the bottom. PATTERN uses djay’s sampler, not a step sequencer. STEMS follows djay’s four-part separation layout, in channel order 4, 3, 2, 1; check the Neural Mix panel to identify the parts. Native RGB pads use bank colors and state brightness; individual on-screen hotcue colors are not copied.

Channel FX selector

The centre FILTER / FX1–4 selector changes what the large channel knobs and round FX ON buttons control.

Channel FX selector
Selected modeChannel amount knobRound FX ON button
FILTERFilterToggle filter active/kill
FX1 / FX2 / FX3Selected slot’s Wet/DryToggle that slot

For momentary FX4, turn HOLD off in djay. Hold the round FX ON button to apply it and release to stop. The amount knob keeps its filter function.

For audio, select MX2 channels 1–2 for the main mix and 3–4 for headphones in djay. MAIN is separate from CUE VOL. Hardware gain can change the audible level without moving djay’s on-screen gain knob.

About these assignments. The core integration was tested on the development Mac with djay Pro 5.6.9. Some secondary gestures are implemented but have not each been physically checked. Native RGB lighting belongs to the Native setup; Windows and Intel Mac builds remain unvalidated.

With Companion

MX2 Companion→Applications
  1. Open the DMG and drag MX2 Companion into Applications.
  2. Connect the MX2, choose Native or MIDI in Companion, then start the connection.
  3. Import the matching mapping in djay and select the virtual MX2 for djay device.

Classic MIDI

The working setup before the app. Requires the Terminal bridge.

  1. Switch the MX2 to MIDI mode.
  2. Run DEMARRER-MX2.command and keep its Terminal window open.
  3. Import Visual Complete in djay and select the virtual MX2 for djay device.

The mapping file alone is not a complete direct MX2 mapping. The included bridge drives its SHIFT layers, pad modes and feedback. Disable djay’s physical Traktor MX2 MIDI input to avoid duplicate commands.

Good to know.

Can I use MIDI mode with Companion?

Yes. Select MIDI in Companion and on the MX2, then use the Visual Complete mapping with the virtual MX2 for djay device in djay.

Is there a complete mapping that works without an app or Terminal?

Not in this release. Visual Complete requires Companion or the included MIDI bridge. Importing that file directly for the physical Traktor MX2 will not provide its SHIFT layers, four pad banks or feedback.

Which audio channels should I choose?

Set the MX2 main output to channels 1–2 and headphones to 3–4 in djay. For a single-deck preview, select the deck’s headphone cue and turn CUE MIX toward CUE.

Why does macOS ask me to approve the app?

This build is not notarized by Apple. If macOS blocks the first launch, open System Settings → Privacy & Security and choose Open Anyway after trying to open the app. See Apple’s instructions.

Does it support Windows or Intel Macs?

The downloadable app is built for Apple silicon Macs. Windows and Intel Mac packages have not been validated on controller hardware.
