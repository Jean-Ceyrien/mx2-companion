Connect your MX2

Connect your MX2 by USB and turn it on. Choose the same mode in Companion and on the controller.

Looking for your controller

You can plug it in at any time.

How do I change mode?

Press both physical SHIFT buttons together once. Wait for the status to update. Blue mode lights can indicate MIDI mode.

While mixing, use each SHIFT separately so you don’t switch the controller’s mode.

02 / 03 · DJAY PRO

Connect to djay

Start the bridge and install the mapping once. Keep Companion open while you mix.

After the first import, quit and reopen djay. Then choose MX2 for djay and Traktor MX2 – Native RGB. Disable the direct Traktor MX2 MIDI connection.

Speakers & headphones

Main outputMX2 · 1–2
Headphone outputMX2 · 3–4

In djay, turn automatic headphone selection off. Turn CUE MIX toward CUE to hear only the selected preview deck. Use the small headphone buttons above the channel faders to select it.

GAIN and MAIN

GAIN changes the level of its own deck. djay can keep the hardware gain separate from its on-screen gain knob, so that knob may stay still even when the level changes.

MAIN controls the main mix output. It does not turn down a track selected for headphone CUE preview. Use CUE VOL for headphone level. To see MAIN in djay, click the speaker icon in the top toolbar.

Start gently

Load one track per deck. Keep headphone volume moderate. Test PLAY and CUE on each side before bringing up the main volume.

If something doesn’t respond

The modes do not match

Choose Native or MIDI in Companion, then use the same mode on the MX2. Press both SHIFT buttons together once to change the hardware mode. Move a control to confirm it.

The crossfader moves when I use a jog

After importing a mapping, quit and reopen djay while keeping Companion open. This cleared the reported jog/crossfader issue in our hardware test. Also keep MIDI → Options → Crossfader Cutting Mode off and disable the direct Traktor MX2 MIDI device.

Nothing happens in djay

Start the bridge. Select MX2 for djay and the supplied mapping in djay. Disable the direct Traktor MX2 MIDI device. Close older bridge windows.

FX4 stays on after release

Turn off the effect’s HOLD option in djay for momentary behavior. Hold the round channel FX button to apply FX4; release to stop it.

I unplugged the controller

Plug it back in. The bridge waits for it. Move any knobs that need to match their position in djay; automatic pickup isn’t implemented by the bridge.

Using Windows

Create one loopMIDI port named MX2 for djay, and use the Windows RGB mapping. WebView2 Runtime is needed for this interface. Windows hardware, lights and audio still need validation.
